Projects

HR Analytics dashboard

I built an HR Analytics Dashboard in Power BI to analyze employee data and provide insights into workforce trends. I cleaned and transformed the data using Power Query, created DAX measures for KPIs like total employees, promotion eligibility, and retrenchment risk, and designed three interactive report pages. The dashboard helps HR teams identify high-performing employees, promotion candidates, and workforce distribution by role, experience, and distance from office. This project strengthened my skills in Power BI, data modeling, and business storytelling.”

Store Data Analysis

This Store Data Analysis dashboard, built in Microsoft Excel, presents key business insights through interactive charts and reports. It analyzes order volume and sales performance across months, states, gender, and age groups, along with order status trends such as delivered, returned, and cancelled orders. The dashboard transforms raw data into meaningful visual insights, helping to understand customer behavior, sales patterns, and overall store performance for better decision-making.
